## Design Context

### Users
People using Codex or other graphical agents on macOS. They create a virtual display for selected application windows while retaining a usable physical desktop for their own work.

### Brand Personality
Calm, precise, dependable. Keep the yomado wordmark lowercase and use the selected night-window identity: a warm ivory window with a moon-shaped notch on a deep navy tile.

### Aesthetic Direction
A refined native macOS utility is the implementation direction for this revision. Use semantic system materials and controls, clear typography, deliberate spacing, and automatic light/dark appearance. Avoid the earlier flat stack of equally prominent buttons, decorative dashboards, neon styling, and fabricated usage statistics.

### Design Principles
- Make virtual-display state, resolution, and actual arrangement immediately understandable.
- Give the ordinary create/stop workflow a clear primary action.
- Keep experimental physical-output changes behind explicit disclosure and confirmation.
- Preserve human desktop control: no automatic third-party window migration or physical-main changes in the ordinary workflow.
- Distinguish display availability from working agent input, monitor power savings, and input isolation.
- Support keyboard navigation, readable contrast, and accessibility labels.
